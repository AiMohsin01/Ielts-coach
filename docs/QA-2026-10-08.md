## Differences from the reference platform

This is an independently built practice platform, not a complete or exact copy of IELTSly. It uses original exercises and notes, with externally embedded YouTube lessons attributed to their creators.

- Vocabulary has 15 topics and 84 words, not the reference site's complete commercial topic catalogue. Pronunciation uses available browser voices, not original audio recordings.
- Reading/listening banks contain short original exercises, not the licensed Cambridge collection or a complete 40-question IELTS exam. Scores are practice scores, not IELTS bands.
- Speaking uses recorded answers, not real-time voice calls. Hosted AI feedback/chat/rewriting requires an available AI service; local Ollama is not available on the current Render host.
- Grammar is a starter quiz plus video lessons. Typing is a 60-second self-practice tool. Tutorials and progress features are smaller in scope than the reference.
- No checkout, paid membership billing, referral attribution or cash rewards are enabled. The interface states these limits.
- The roadmap is rule-based, not the reference site's proprietary adaptive engine. Completion is self-reported. Rebuilding fills missing days and preserves existing activities, including pending ones; changed goals do not silently replace already scheduled work. Roadmaps support an exam date within the next 365 days.
- Free Render hosting can sleep between visits; uploaded audio on its local filesystem is not durable across deployments. Persistent object storage is still needed for production audio retention.

Use the regression command `npm run test:regression` against a development database before publishing future changes. Never run destructive test cleanup against the production database.
